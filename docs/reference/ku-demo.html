背答案的学生

一个学生把练习册的答案全背了下来。练习册上的题他全对，可一换成没见过的新题，他就不会了。模型也会犯同样的错，这叫过拟合。

右边这张图里，蓝点是模型学习时看到的数据，橙圈是它从没见过的新数据。模型要做的，是找一条曲线去“解释”这些点。

拖动滑块，改变曲线能有多弯，也就是多项式的阶数：

1–2 阶曲线太直，连蓝点都对不上。这是欠拟合，像没复习的学生。
3–5 阶曲线大致跟着点走，橙圈也离得不远。这是我们想要的。
9 阶以上曲线穿过了每一个蓝点，却在点和点之间乱跳，离橙圈越来越远。这就是背答案。

判断模型好不好，要看它在没见过的数据上表现如何，而不是在练习题上。所以我们总要留一部分数据不给模型看，专门用来考它。

训练误差和测试误差

模型是一个 d 阶多项式，用最小二乘法在 N 个训练点上求系数 w：

f(x) = w0 + w1x + w2x2 + … + wdxd
L(w) = (1/N) Σi ( f(xi) − yi )2

阶数 d 越高，模型能表示的函数越多，训练误差只会下降或不变。当 d ≥ N − 1 时，总能找到一条曲线穿过所有训练点，训练误差降到 0。

测试误差不一样。它先随 d 下降，到某个位置后开始上升，画出来是一个 U 形。右下角的图就是这条 U 形曲线。

U 形左侧误差大，是因为模型太简单，系统性地偏离真实规律（偏差大）。右侧误差大，是因为模型把训练数据里的噪声也学了进去，换一批数据结果就大不相同（方差大）。下一个 KU“偏差与方差”会展开讲。

延伸阅读：Simon Prince，《Understanding Deep Learning》第 8 章。
